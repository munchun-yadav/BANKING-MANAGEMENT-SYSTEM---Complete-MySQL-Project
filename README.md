
# Banking India SQL Project

## Overview
This project is a **Banking Management System** database built in SQL. It simulates real-world Indian banking operations and contains realistic sample data for learning, practice, analytics, and SQL interview preparation.

## Database Name
`BankingIndia`

## Features
- Branch Management
- Customer Management
- Employee Records
- Bank Accounts
- Transactions
- Loans
- Cards Management
- KYC Tracking
- Financial Analysis Queries

## Database Structure

### Main Tables
1. branches
2. customers
3. employees
4. accounts
5. transactions
6. loans
7. cards

## Project Files

### 1. banking india dataset.sql
Contains:
- Database creation script
- Table creation statements
- Relationships and foreign keys
- Sample banking data

### 2. PROJECT OF FINANCE.sql
Contains:
- Data quality checks
- Duplicate record detection
- NULL value analysis
- Invalid data identification
- Standardization queries
- Financial reporting practice queries
